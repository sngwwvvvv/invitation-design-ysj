# Extractable Components

The project has no framework components to convert into reusable Superdesign `DraftComponent` entities. The following page-local visual regions are conceptual sections only and remain inline in `index.html`:

- `InvitationIntro` — intro background, logo, title, date/time, invitation message
- `ProfileSection` — representative portrait and career list
- `MapSection` — static route capture, address, transit guidance, map link, parking notice
- `AccountNotice` — bank details, clipboard action, live status

No layout component is shared across multiple routes, so component extraction should be skipped.
