# Invitation 640px Scaled Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the invitation retain its 640px layout and line breaks when visually scaled down through 360px, while correcting the intro order and moving the account notice into the account card.

**Architecture:** The remote Superdesign HTML remains a single static invitation. A 640px canonical canvas is visually scaled as one unit below 640px; its wrapper reserves the corresponding scaled height so later sections do not overlap. The local design-system document supplies the generation constraints, and the Node contract validator checks the static HTML contracts before browser QA checks the rendered 360px, 430px, and 640px views.

**Tech Stack:** Superdesign CLI, static HTML/CSS/JavaScript generated by Superdesign, Node.js built-ins, Codex in-app browser / Playwright evidence.

## Global Constraints

- Source draft: `3098fb65-2a1d-4482-befb-f7e7cf88c2bd`; use one `--mode branch` iteration only.
- Canonical visual layout width is exactly 640px. At viewport widths 360px through 639px, render the full invitation at `viewport-width / 640` scale; do not introduce per-element responsive typography or `white-space: nowrap`.
- Preserve the original 640px line breaks at 360px and 430px, with no horizontal overflow, clipping, or section overlap.
- Keep the five approved colors only: `#0A2D54`, `#0063A6`, `#43A64E`, `#F0F4F8`, `#64748B`.
- Keep the horizontal logo unfiltered and uncropped, the 40%-opaque `reflection_background.png` intro layer, profile/map/transit/parking content, Naver Map link, and digits-only account copy `04908774202501`.
- Intro sequence is logo → unchanged main heading → `#event-details` → invitation message.
- Inside the account card, show the exact notice copy, a solid divider, and these exact label/value pairs: `은행: 우리은행`, `계좌번호: 049-087742-02-501`, `예금주: 윤성중`.

- [ ] **Step 3: Update the Superdesign context with the exact rendering model**

  Add a `640px canonical canvas` subsection to `.superdesign/design-system.md` with this exact DOM, CSS, and JavaScript model. This narrow resize script is the sole allowed JavaScript layout behavior; it synchronizes the visual transform with its parent's document-flow height.

  ```html
  <div class="invitation-stage">
    <div id="invitation-scale-frame" class="invitation-scale-frame">
      <main id="invitation-canvas" class="invitation-canvas">
        <!-- all existing invitation sections, including #intro-section and #account-card -->
      </main>
    </div>
  </div>
  ```

  ```css
  .invitation-stage { display: flex; justify-content: center; width: 100%; }
  .invitation-scale-frame { width: min(640px, 100vw); overflow: clip; }
  .invitation-canvas {
    width: 640px;
    transform-origin: top left;
    will-change: transform;
  }
  ```

  ```js
  const frame = document.getElementById('invitation-scale-frame');
  const canvas = document.getElementById('invitation-canvas');
  const syncInvitationScale = () => {
    const scale = Math.min(1, window.innerWidth / 640);
    canvas.style.transform = `scale(${scale})`;
    frame.style.height = `${canvas.scrollHeight * scale}px`;
  };
  new ResizeObserver(syncInvitationScale).observe(canvas);
  window.addEventListener('resize', syncInvitationScale, { passive: true });
  syncInvitationScale();
  ```

  Follow the DOM and code above with these constraints:

  ```markdown
  - Wrap all visible invitation content in `#invitation-scale-frame` and `#invitation-canvas`.
  - `#invitation-canvas` has `width: 640px`; below 640px it is transformed from `top left` by `window.innerWidth / 640`.
  - The frame reserves the transformed visual height so the document flow has no overlap or blank gap.
  - Do not change a child font size, child width, spacing, or wrapping rule at narrower widths.
  - Put `#intro-section` and its `.intro-bg` inside `.invitation-canvas`; preserve the full section background when scaled.
  - Put the exact account notice, `#account-divider`, account labels, values, copy button, and live region inside `#account-card`.
  ```
