# 초청장 640px 기준 비례 축소 및 섹션 레이아웃 수정 명세

## 1. 목표

최종 Superdesign 초청장 드래프트를 **640px 너비의 기준 캔버스**로 설계한다. 뷰포트가 360px부터 639px 사이일 때는 640px 캔버스 전체를 뷰포트 폭에 맞춰 동일 비율로 축소한다. 따라서 360px 화면에서도 640px 화면과 동일한 줄바꿈, 정보 배치, 여백 비율, 배경 범위를 보여야 한다.

이 변경은 텍스트별 줄바꿈 금지나 개별 글꼴 크기 재조정으로 구현하지 않는다. 로고·제목·본문·버튼·이미지·배경을 포함한 초청장 전체가 하나의 비례 축소 단위여야 한다.

## 2. 범위와 기준 드래프트

- 수정 대상 드래프트: `3098fb65-2a1d-4482-befb-f7e7cf88c2bd`
- 기준 폭: 640 CSS px
- 축소 적용 범위: 뷰포트 폭 360px 이상 639px 이하
- 640px 이상에서는 기존의 중앙 정렬 640px 단일 열 캔버스를 원래 크기로 표시한다.
- 360px 미만의 화면은 이번 범위에 포함하지 않는다.

## 3. 비례 축소 레이아웃

### 3.1 캔버스와 스케일

- 초청장 콘텐츠 쉘은 항상 640px 기준으로 레이아웃한다.
- 뷰포트가 640px보다 좁을 때의 배율은 `viewport width / 640`이다.
- 예: 360px에서는 `0.5625` 배율로 축소한다.
- 축소 대상은 글자·이미지·아이콘·테두리·여백·버튼·배경을 모두 포함한다.
- 축소 후의 시각적 폭은 뷰포트 폭을 넘지 않아야 하며 가로 스크롤이나 잘림이 없어야 한다.
- 레이아웃의 실제 높이도 축소된 높이와 일치시켜, 뒤따르는 섹션이 겹치거나 빈 여백이 생기지 않게 한다.

### 3.2 줄바꿈과 접근성

- 360px, 430px, 640px에서 각 문장의 줄바꿈 위치와 줄 수는 640px 기준과 동일해야 한다.
- 임의의 `white-space: nowrap`은 사용하지 않는다.
- 개별 요소의 반응형 글꼴 크기나 여백 변경으로 줄바꿈을 맞추지 않는다.
- 키보드 포커스, 버튼 동작, 스크린 리더용 레이블과 라이브 영역은 축소 상태에서도 유지한다.

## 4. 도입부 순서와 배경

`#intro-section`은 다음 순서의 한 연속된 컨테이너로 구성한다.

1. 가로형 호연회계법인 로고
2. 메인 제목: `호연회계법인에서의 새로운 출발을 알려드립니다`
3. `#event-details` 일시·장소 강조 블록
4. 초청 인사말

- 기존의 제목 → 초청 인사말 → 행사 정보 순서는 사용하지 않는다.
- `reflection_background.png` 배경 레이어는 `#intro-section`의 전체 640px 기준 영역을 덮는다.
- 배경 레이어에만 40% 투명도를 적용하고, 로고·텍스트·행사 정보는 불투명하게 유지한다.
- 배경은 비례 축소 쉘 내부에 포함해야 하며, 360px에서도 배경의 오른쪽·아래쪽이 잘리거나 별도 크롭되지 않아야 한다.

## 5. 계좌 안내 카드

- `축하의 마음을 전하고자 하시는 분들을 위해 계좌 정보를 조심스럽게 안내드립니다.` 문구를 계좌 안내 카드 **안쪽 상단**에 배치한다.
- 이 안내 문구와 계좌 정보 행 사이에는 전체 카드 폭을 따라가는 실선 구분선을 둔다.
- 카드에는 다음 레이블과 값을 정확하게 표시한다.

| 레이블 | 값 |
| --- | --- |
| 은행 | 우리은행 |
| 계좌번호 | `049-087742-02-501` |
| 예금주 | 윤성중 |

- 계좌번호를 가장 강하게 강조하며, 복사 버튼은 기존대로 하이픈 없는 `04908774202501`만 복사한다.
- `축하의 말씀` 제목, 계좌 모달, 모달 실행 버튼은 사용하지 않는다.

## 6. 유지 사항

- 사용 색상: `#0A2D54`, `#0063A6`, `#43A64E`, `#F0F4F8`, `#64748B`
- 가로형 로고의 원본 비율·색상·필터 없음
- 프로필, 정적 지도, 2호선 안내, 네이버 지도 버튼, 주차 안내의 콘텐츠와 순서
- 계좌정보 복사 성공·실패 라이브 영역과 44px 기준 버튼 터치 영역

## 7. 검증 기준

1. Playwright 스크린샷에서 640px과 360px의 각 문장 줄 수와 줄바꿈 위치가 동일하다.
2. 360px에서 초청장 시각 폭이 화면 폭 이내이며 가로 스크롤, 콘텐츠 잘림, 섹션 겹침이 없다.
3. 360px에서 `#intro-section` 배경 이미지가 섹션의 전체 시각 영역을 덮고 잘리지 않는다.
4. 인트로의 순서가 메인 제목 → `#event-details` → 초청 인사말이다.
5. 계좌 안내 문구가 계좌 카드 내부에 있고, 실선 아래에 은행·계좌번호·예금주 정보가 표시된다.
6. 은행/계좌번호/예금주의 레이블과 값이 이 명세의 표기와 정확히 일치한다.
7. 360px·430px·640px에서 계좌정보 복사 버튼이 `04908774202501`만 복사하고 성공 상태를 라이브 영역에 표시한다.
