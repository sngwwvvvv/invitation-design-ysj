# 초청장 헤더 및 컬러 팔레트 수정 명세

## 1. 목표

기존 호연회계법인 개업 초청장 드래프트의 콘텐츠와 섹션 순서는 유지하면서, 확정 컬러 팔레트를 적용하고 헤더·초청 인사말·행사 정보를 하나의 자연스러운 도입부로 재구성한다.

메인 제목인 `호연회계법인에서의 새로운 출발을 알려드립니다`는 변경하지 않는다.

## 2. 수정 범위

- Superdesign 드래프트 ID: `09814ba2-f71a-4d01-a3be-9ae06580b185`
- 수정 대상:
  - 전체 컬러 팔레트와 색상 위계
  - 헤더 및 초청 인사말 영역
  - 일시 및 장소 강조 영역
  - 헤더 로고
  - 계좌 안내 영역과 계좌번호 복사 동작
- 유지 대상:
  - 메인 제목 문구
  - 인물 소개, 오시는 길, 주차 안내의 콘텐츠와 표시 순서
  - 기존 단일 열 초청장 레이아웃과 모바일 중심 폭

## 3. 컬러 시스템

| 역할 | 색상 | 적용 대상 |
| --- | --- | --- |
| Platinum Cool Gray | `#F0F4F8` | 초청장 전체 배경과 넓은 여백 |
| Deep Navy | `#0A2D54` | 메인 제목, 핵심 정보, 주요 로고 주변 텍스트 |
| Slate Steel | `#64748B` | 인사말, 오시는 길, 주차 안내 등 본문 |
| Standard Blue | `#0063A6` | 섹션 제목, 구분선, 영문 슬로건 |
| Vivid Green | `#43A64E` | 달력 아이콘, 지도 핀, 강조 버튼 등 제한된 포인트 |

색상 면적은 쿨 그레이와 슬레이트 계열을 약 80%, 네이비·블루·그린을 약 20%로 사용한다. 그린은 시선을 유도할 필요가 있는 소수 요소에만 사용하며 넓은 배경색으로 사용하지 않는다.

## 4. 도입부 구조

### 4.1 통합 컨테이너

기존의 헤더와 별도 초청 인사말 섹션을 하나의 연속된 컨테이너로 합친다. 컨테이너 내부 순서는 다음과 같다.

1. 가로형 호연회계법인 로고
2. 메인 제목
3. 초청 인사말
4. 일시 및 장소 강조 박스

섹션 사이에 기존처럼 서로 다른 네이비 카드가 끊어져 보이는 간격이나 외곽선은 두지 않는다. 충분한 내부 여백과 구분선으로 정보 위계를 만든다.

### 4.2 배경 이미지와 투명도

- 배경 이미지: `/img/reflection_background.png`
- 배경 이미지는 통합 컨테이너 전체를 덮도록 배치한다.
- 이미지 레이어에만 40% 투명도를 적용한다.
- 로고와 텍스트에는 투명도가 상속되지 않아야 한다.
- 구현 시 통합 컨테이너의 가상 요소에 배경 이미지와 `opacity: 0.4`를 적용하고, 콘텐츠는 그 위의 불투명 레이어에 배치한다.
- 별도의 색상 오버레이는 추가하지 않는다. 이미지가 40% 투명도로 Platinum Cool Gray 배경 위에 표시되도록 한다.

### 4.3 로고

- `/img/hoyeon_logo_horizontal.png`를 사용한다.
- 이미지 원본의 색상을 변경하거나 단색 필터를 적용하지 않는다.
- 원본 비율을 유지하고 잘라내지 않는다.
- 배경 위에서 로고가 분명히 읽히도록 주변에 충분한 여백을 둔다.

### 4.4 메인 제목과 인사말

- 메인 제목은 `호연회계법인에서의 새로운 출발을 알려드립니다`를 그대로 유지한다.
- 메인 제목은 Deep Navy를 사용하며 도입부에서 가장 높은 텍스트 위계를 갖는다.
- 초청 인사말은 메인 제목 아래에 배치하고 Slate Steel을 사용한다.
- 제목과 인사말은 같은 컨테이너 안에서 자연스럽게 이어지되, 글자 크기와 행간으로 명확히 구분한다.

### 4.5 일시 및 장소 강조 박스

- `[일시 및 장소]` 문구는 완전히 삭제한다.
- 일시와 장소 문구는 초청 인사말 아래의 별도 `div`에 배치한다.
- 강조 박스는 통합 컨테이너 내부에 존재하지만 배경·테두리·여백으로 독립된 정보 단위임을 보여준다.
- 행사 일시는 장소보다 한 단계 강하게 표시한다.
- 텍스트는 Deep Navy를 기본으로 사용하고, 일시 앞에는 달력 아이콘, 장소 앞에는 지도 핀 아이콘을 배치해 Vivid Green으로 표시한다.
- 기존 placeholder 값인 `202X년 X월 X일(X) 오후 X시`와 `서울특별시 강남구 테헤란로81길 14, 8층`은 그대로 유지한다.

## 5. 나머지 섹션 적용

- 카드 전체를 짙은 네이비로 채우는 현재 방식은 제거한다.
- 전체 배경과 카드의 넓은 면적은 Platinum Cool Gray와 그에 가까운 밝은 면으로 정리한다.
- `경력사항 소개`, `오시는 길` 등의 유지되는 섹션 제목은 Standard Blue를 사용한다.
- 구분선은 Standard Blue를 사용하되 제목보다 낮은 시각적 강도로 표현한다.
- 경력, 주소, 교통, 주차 안내 등의 본문은 Slate Steel을 사용한다.
- 네이버 지도 버튼은 Standard Blue를 사용한다. 계좌정보 복사 버튼은 Deep Navy를 사용하고, 버튼 내부의 작은 강조 아이콘에는 Vivid Green을 사용한다.
- 프로필 사진, 지도 이미지, 2호선 아이콘은 원본 비율을 유지한다.

## 6. 계좌 안내 영역

### 6.1 문구와 구조

- `축하의 말씀` 제목은 삭제한다.
- 제목을 대체하는 별도 `h2`는 추가하지 않는다.
- 메인 안내 문구는 `축하의 마음을 전하고자 하시는 분들을 위해 계좌 정보를 조심스럽게 안내드립니다.`로 표시한다.
- `마음 전하실 곳 확인하기` 버튼과 계좌정보 모달은 제거한다.
- 계좌 정보는 같은 페이지의 안내 문구 바로 아래에 항상 표시한다.

### 6.2 계좌 정보 표시

다음 정보를 밝은 계좌 안내 카드 안에 표시한다.

| 항목 | 값 |
| --- | --- |
| 은행 | 우리은행 |
| 계좌번호 | `049-087742-02-501` |
| 계좌주 | 윤성중 |

- 계좌번호를 카드에서 가장 강하게 강조하고 Deep Navy를 사용한다.
- 은행과 계좌주는 Slate Steel 본문보다 높은 굵기로 표시한다.
- 카드의 넓은 면적은 Platinum Cool Gray 계열을 유지하고, Standard Blue 구분선과 Vivid Green의 작은 포인트만 사용한다.

### 6.3 계좌정보 복사

- 계좌 카드 안에 `계좌정보 복사` 버튼을 제공한다.
- 버튼 클릭 시 계좌번호만 클립보드에 복사한다.
- 복사되는 정확한 문자열은 하이픈이 제거된 `04908774202501`이다.
- 은행명과 계좌주명은 복사하지 않는다.
- 복사 성공 시 버튼 주변에 `계좌번호가 복사되었습니다.`라는 짧은 상태 안내를 표시한다.
- 클립보드 API를 사용할 수 없거나 복사에 실패하면 `계좌번호를 길게 눌러 복사해 주세요.`라는 대체 안내를 표시한다.
- 상태 안내는 스크린 리더가 인식할 수 있도록 라이브 영역으로 제공한다.

## 7. 반응형 및 접근성

- 기존 단일 열 구조를 유지하고 데스크톱에서도 초청장 폭을 중앙 정렬한다.
- 모바일에서 본문은 16px 이상, 주요 버튼의 터치 영역은 44px 이상을 유지한다.
- 배경 이미지 위의 모든 텍스트는 읽을 수 있는 명도 대비를 확보한다.
- 로고와 이미지에는 기존 대체 텍스트를 유지하거나 의미에 맞게 보완한다.
- 색상만으로 정보 의미를 전달하지 않으며, 제목·여백·테두리·아이콘을 함께 사용한다.

## 8. 검증 기준

- 메인 제목 문구가 변경되지 않는다.
- `[일시 및 장소]` 문구가 화면에 존재하지 않는다.
- 헤더와 초청 인사말이 하나의 연속된 컨테이너 안에 표시된다.
- `reflection_background.png`가 해당 통합 컨테이너의 배경으로 표시되고 배경 레이어만 40% 투명하다.
- `hoyeon_logo_horizontal.png`가 원본 색상과 비율로 표시된다.
- 일시와 장소가 별도 강조 `div` 안에 표시된다.
- 지정한 다섯 가지 색상만 주요 UI 컬러로 사용되고 80:20 면적 원칙을 따른다.
- 모바일 및 데스크톱 화면에서 텍스트, 프로필 사진, 지도, 버튼이 잘리거나 겹치지 않는다.
- 인물 소개, 오시는 길, 주차 안내의 기존 콘텐츠와 순서가 유지된다.
- `축하의 말씀` 제목과 계좌정보 모달을 여는 버튼이 화면에 존재하지 않는다.
- 계좌 안내 문구와 우리은행 계좌 정보가 페이지에 직접 표시된다.
- 계좌정보 복사 버튼을 누르면 `04908774202501`만 클립보드에 저장된다.
- 복사의 성공과 실패 상태가 화면과 스크린 리더에 안내된다.
