# 개업식 초청장 모바일 우선 구현 설계

## 1. 목적과 우선순위

호연회계법인 윤성중 부대표의 개업식 초청장을 프레임워크 없이 정적 HTML과 CSS로 구현한다. 주 사용 환경은 모바일이며, **360px 뷰포트를 기준으로 설계**한다.

기존의 640px 기준 캔버스를 화면 전체와 함께 비례 축소하는 요구는 이 설계로 대체한다. 360px에서 640px의 레이아웃을 56.25%로 축소하면 본문 16px이 약 9px이 되어 고령 사용자를 위한 가독성 목표를 만족하지 못하기 때문이다. 640px 드래프트의 색상, 위계, 이미지 비율은 시각 참고 자료로만 사용한다.

## 2. 산출물과 제약

- `index.html`: 의미론적 마크업과 계좌번호 복사에 필요한 최소 인라인 JavaScript
- `styles.css`: 모든 스타일
- 로컬 `img/`의 제공 자산만 사용
- 프레임워크, 외부 폰트, 외부 아이콘 라이브러리, iframe, 지도 API, 서버 요청을 사용하지 않음
- 유일한 외부 이동은 네이버 지도 장소 확인 링크임

## 3. 레이아웃 원칙

### 3.1 모바일 기준과 큰 화면

- 콘텐츠 셸은 `width: 100%`, `max-width: 640px`으로 하고 큰 화면에서 중앙 정렬한다.
- 360px에서 본문은 최소 16px, 주소·지도 버튼은 18px 이상으로 표시한다.
- 640px 드래프트의 줄바꿈을 강제하지 않는다. 좁은 화면에서 제목, 행사 정보, 경력 문구가 자연스럽게 줄바꿈될 수 있다.
- 주요 버튼은 최소 44px 높이를 갖고, 키보드 포커스가 보인다.

### 3.2 색상과 서체

주요 UI 색상은 다음 다섯 가지로 제한한다.

| 역할 | 색상 |
| --- | --- |
| 넓은 배경 | `#F0F4F8` |
| 핵심 제목·계좌번호·복사 버튼 | `#0A2D54` |
| 섹션 제목·지도 버튼·구분선 | `#0063A6` |
| 작은 아이콘·제한된 포인트 | `#43A64E` |
| 본문·보조 정보 | `#64748B` |

시스템 산세리프 글꼴만 사용한다. 넓은 면적은 쿨 그레이와 밝은 중성색으로 구성하고, 네이비·블루·그린은 정보 위계와 제한된 포인트에만 사용한다. 그라데이션, 강한 그림자, 애니메이션, 과도한 둥근 카드 효과는 사용하지 않는다.

## 4. 정보 구조와 구성 요소

### 4.1 도입부 (`#intro-section`)

도입부는 하나의 연속된 영역으로 다음 순서로 배치한다.

1. `img/hoyeon_logo_horizontal.png` 가로형 로고
2. `호연회계법인에서의 새로운 출발을 알려드립니다` 제목
3. `#event-details` 행사 일시·장소 강조 블록
4. 확정 전 초청 인사말 placeholder

`img/reflection_background.png`는 가상 요소 배경 레이어로 전체 도입부를 덮고, 해당 레이어에만 `opacity: 0.4`을 적용한다. 로고와 모든 텍스트는 불투명하게 표시한다. 로고는 필터·색상 변경·크롭 없이 원본 비율을 유지한다.

행사 정보에는 다음 placeholder를 표시한다.

- `202X년 X월 X일(X) 오후 X시`
- `서울특별시 강남구 테헤란로81길 14, 8층`

달력과 위치 핀은 외부 라이브러리 없이 CSS 또는 짧은 인라인 SVG로 만들며, Vivid Green을 제한적으로 사용한다.

### 4.2 경력사항 소개

- 제목: `경력사항 소개`
- 인물: `윤성중 부대표`
- 사진: `img/portrait_ysj.png`
- 사진과 경력은 360px에서도 읽을 수 있는 2열 구조로 유지하되, 사진은 원본 비율을 유지하고 잘라내지 않는다.
- 사진의 하단과 열려 있는 주요 경력 열의 하단을 가능한 한 맞춘다.
- 전화번호, 휴대전화, 이메일, 학력, 자격 정보는 표시하지 않는다.
- `initial_ideas.md`에 제공된 주요 경력 10개 항목을 처음부터 모두 표시하고 임의로 수정하지 않는다.

### 4.3 오시는 길

다음 순서를 유지한다.

1. `img/map_capture.png` 정적 지도 이미지
2. `서울특별시 강남구 테헤란로81길 14, 8층 (카이마빌딩)`
3. `img/Seoul_Metro_Line_2.svg.webp` 아이콘과 `2호선 삼성역 5번출구에서 도보 약 10분`
4. 네이버 지도에서 주소 검색 결과와 장소 정보를 여는 `네이버 지도에서 확인하기` 링크
5. 주차 안내 placeholder: `[주차 안내가 확정되면 이곳에 표시됩니다]`

지도·2호선 아이콘은 원본 비율을 유지한다. 지도 로드에 실패해도 주소, 교통 안내, 지도 링크, 주차 안내가 계속 보이도록 `alt` 텍스트와 독립 텍스트를 제공한다.

### 4.4 계좌 안내

별도 제목과 모달 없이 안내 문구와 계좌 카드를 페이지에 직접 표시한다.

> 축하의 마음을 전하고자 하시는 분들을 위해 계좌 정보를 조심스럽게 안내드립니다.

카드에는 실선 구분선 아래에 다음 값을 항상 표시한다.

| 항목 | 값 |
| --- | --- |
| 은행 | 우리은행 |
| 계좌번호 | `049-087742-02-501` |
| 예금주 | 윤성중 |

계좌번호는 Deep Navy로 가장 강하게 강조한다. `계좌정보 복사` 버튼은 `navigator.clipboard.writeText('04908774202501')`를 사용하여 숫자만 복사한다. 성공하면 `계좌번호가 복사되었습니다.`, 실패하면 `계좌번호를 길게 눌러 복사해 주세요.`를 `aria-live="polite"` 상태 영역에 표시한다.

## 5. 접근성·실패 처리

- 섹션에는 의미 있는 `header`, `main`, `section`, `h1`, `h2` 구조를 사용한다.
- 모든 이미지에 목적을 설명하는 대체 텍스트를 제공한다.
- 색상만으로 정보를 구분하지 않고 제목, 여백, 테두리, 아이콘을 함께 사용한다.
- 클립보드 접근이 실패해도 화면의 계좌번호를 그대로 읽고 길게 눌러 복사할 수 있다.
- 링크와 버튼에는 명확한 포커스 스타일을 제공한다.

## 6. 검증 계획

구현 후 다음을 확인한다.

1. 360px에서 가로 스크롤 없이 제목·행사 정보·경력·지도·계좌 카드가 읽히고 겹치지 않는다.
2. 640px 이상에서 초청장이 중앙에 정렬되고 최대 폭을 넘지 않는다.
3. 본문이 16px 이상이고, 버튼의 높이가 44px 이상이다.
4. 로고, 인물 사진, 지도, 2호선 아이콘이 왜곡·크롭 없이 표시된다.
5. 지도 API·iframe·프레임워크·외부 폰트·외부 아이콘 라이브러리가 없다.
6. 네이버 지도 링크만 외부 이동을 만들며, 지도 주소 검색 결과를 직접 연다.
7. 복사 버튼이 정확히 `04908774202501`만 복사하고 성공·실패 안내가 라이브 영역에 표시된다.
8. 360px·640px 스크린샷으로 여백, 줄바꿈, 이미지 비율, 대비를 점검한다.
