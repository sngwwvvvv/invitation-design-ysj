# 초청 인사말 표시 설계

## 목표

확정된 초청 인사말을 `#intro-section`의 행사 정보 아래에 표시한다. 원문의 강제 줄바꿈은 사용하지 않고 문단 사이의 간격만 유지하면서, 좁은 화면에서는 콘텐츠가 넘치지 않도록 자연스러운 줄바꿈을 허용한다. 배경 이미지 위에서도 인사말이 분명하게 읽혀야 한다.

## 콘텐츠 구조

- 기존 `.invitation-message` 자리표시자를 `id="invitation-message"`를 가진 실제 인사말 컨테이너로 교체하고 기존 클래스는 스타일 연결을 위해 유지한다.
- 인사말 본문은 의미 단위별 문단으로 나누고, 문단 내부에는 강제 줄바꿈을 넣지 않는다.
- 문단 사이 간격은 CSS로 표현해 빈 문단이나 `<br>`에 의존하지 않는다.
- 마지막 날짜·직함·이름은 별도의 서명 영역으로 분리한다.
- 본문은 왼쪽 정렬하고 서명 영역은 오른쪽 정렬한다.

## 시각 디자인

- 별도 배경 패널·테두리·그림자는 사용하지 않는다.
- 본문은 네이비 계열의 굵은 글꼴, 충분한 줄 높이, 미세한 텍스트 그림자로 강조한다.
- 인사말 너비는 인트로 영역 안에서 제한하고 중앙에 배치한다.
- 모바일에서는 글자 크기와 좌우 여백을 조정하고 브라우저의 자연 줄바꿈을 사용한다.

## 접근성과 동작

- 텍스트는 이미지가 아닌 실제 HTML 텍스트로 유지한다.
- 문서 읽기 순서는 기존대로 제목, 행사 정보, 초청 인사말 순서를 유지한다.
- 인사말 때문에 가로 스크롤이나 텍스트 잘림이 생기지 않아야 한다.
- 장식 요소는 콘텐츠 의미를 방해하지 않아야 한다.

## 검증

1. 자리표시자 문구가 제거되고 확정 문구가 정확히 포함되어야 한다.
2. 다섯 개 본문 문단과 서명 영역이 구분되어야 한다.
3. 본문 내부에 강제 줄바꿈이 없고 문단 간 CSS 간격이 적용되어야 한다.
4. 본문 왼쪽 정렬, 서명 오른쪽 정렬, 굵은 고대비 글꼴 스타일이 적용되어야 한다.
5. 기존 로컬 검증 스크립트가 통과해야 한다.
6. 데스크톱과 모바일 화면에서 가로 넘침 없이 인사말이 또렷하게 보여야 한다.
