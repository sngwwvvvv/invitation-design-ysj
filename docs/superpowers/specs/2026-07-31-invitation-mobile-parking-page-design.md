# 행사장 기준 모바일 주차 안내 페이지 설계

## 배경

현재 초대장의 주차 버튼은 네이버 지도에서 `주차장`을 검색하지만, 모바일에서는 사용자의 현재 위치를 기준으로 주변 결과가 표시될 수 있다. 행사장 기준으로 안내하려면 초대장 내부에 행사장 좌표를 고정한 모바일 안내 페이지를 제공하고, 각 주차장 항목에서 네이버 지도로 이동하도록 한다.

## 목표

- 주차 안내 버튼 클릭 시 같은 사이트의 모바일 주차 안내 페이지를 새 탭으로 연다.
- 행사장 주소 `서울특별시 강남구 테헤란로81길 14`와 고정 좌표 `37.508067198284, 127.05714966107`를 페이지에 명시한다.
- 행사장 기준으로 확인한 인근 주차장 목록을 보여준다.
- 각 주차장 항목은 해당 장소명으로 네이버 지도 검색을 새 탭에서 연다.
- 네이버 지도 API 키나 위치 권한에 의존하지 않는다.
- 요금과 운영시간처럼 변동 가능하거나 확인되지 않은 정보는 임의로 표시하지 않는다.

## 사용자 흐름

1. 초대장 하단의 `인근 주차장 확인하기` 버튼을 누른다.
2. 새 탭에서 `parking.html`이 열린다.
3. 행사장 주소와 행사장 기준 안내 문구를 확인한다.
4. 인근 주차장 목록에서 원하는 장소를 누른다.
5. 네이버 지도에서 해당 주차장 검색 결과를 확인한다.

## 화면 구성

### 상단 안내

- 페이지 제목: `주차장 안내`
- 경고 문구: `❗ 본 건물에는 주차가 불가합니다.`
- 보조 문구: `죄송하지만 인근 유료주차장 이용을 부탁드립니다.`
- 행사장 주소와 “행사장 위치 기준으로 정리한 목록”이라는 기준 설명

### 위치 기준 카드

- 기존 행사장 지도 이미지(`img/map_capture.png`)를 사용한다.
- 이미지 대체 텍스트에 행사장 주소를 포함한다.
- 행사장 주소를 네이버 지도에서 여는 보조 링크를 제공한다.

### 주차장 목록

현재 네이버 지도에서 행사장 주변으로 확인되는 다음 장소를 정적 목록으로 제공한다.

- 서울 선릉과 정릉 민영 주차장
- 삼성제일민영주차장
- 삼성제일주차장
- 아마노 토펙신사옥 주차장
- 테헤란로69길노상공영주차장
- 송현빌딩 주차장
- 시큐어파킹 JUSTCO 삼성점 민영 주차장
- 테헤란로26길주차장
- 나이스파크 강남 저스트코타워 주차장

각 항목은 `https://map.naver.com/p/search/{장소명}` 형식의 URL을 사용하고 `target="_blank"`와 `rel="noopener"`를 적용한다. 가격, 주차 가능 여부, 운영시간은 네이버 지도에서 최신 내용을 확인하도록 안내한다.

## 기술 설계

- `index.html`: 기존 주차 버튼의 목적지를 `parking.html`로 변경하고 새 탭 동작을 유지한다.
- `parking.html`: 접근 가능한 정적 HTML로 안내 문구, 좌표, 지도 이미지, 주차장 링크를 렌더링한다.
- `parking.css`: 모바일 우선 레이아웃, 기존 초대장 색상 토큰과 조화를 이루는 카드/버튼/포커스 상태를 정의한다.
- 외부 지도 SDK, iframe, 위치 권한, 서버 API는 사용하지 않는다.
- 기존 행사장 네이버 지도 링크는 유지한다. 새 안내 페이지의 주차장 링크는 개별 장소 확인용으로 추가된다.

## 접근성 및 반응형 기준

- 문서 언어는 `ko`로 설정한다.
- 링크는 키보드 포커스 표시를 제공한다.
- 터치 대상은 최소 44px 높이를 확보한다.
- 360px 폭에서 가로 스크롤 없이 읽을 수 있어야 한다.
- 외부 링크에는 새 탭 및 `noopener` 속성을 적용한다.

## 검증 기준

- 정적 검증 스크립트가 주소, 좌표, 목록 9개, 링크 보안 속성, 반응형 관련 CSS를 확인한다.
- Playwright 모바일 뷰포트에서 `parking.html`을 열어 제목·주소·목록이 표시되는지 확인한다.
- 첫 번째 주차장 링크가 네이버 지도 검색 URL을 가리키는지 확인한다.
- 기존 초대장 검증과 전체 테스트가 통과한다.

## 비목표 및 후속 개선

- 이 버전에서는 실시간 주차면, 요금, 운영시간을 수집하지 않는다.
- 추후 실시간 데이터가 필요하면 네이버 지도 링크를 통한 최신 확인을 유지하면서 별도 데이터 제공 방식과 갱신 정책을 검토한다.
