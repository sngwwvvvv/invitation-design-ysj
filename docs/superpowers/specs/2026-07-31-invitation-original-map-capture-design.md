# 초청장 원본 지도 캡처 적용 설계

## 목적

초청장 지도는 정밀한 길찾기 수단이 아니라 삼성역과 행사장의 대략적인 위치 관계를 보여주는 방향 안내 이미지로 사용한다. 정확한 이동 경로와 주변 상세 정보는 기존 `네이버 지도에서 확인하기` 버튼이 담당한다.

## 현재 상태

- `img/map_capture.png`는 삼성역과 행사장을 한 화면에 포함하지만, 넓은 영역을 담아 지도 내부의 작은 상호명과 도로명은 모바일에서 읽기 어렵다.
- `img/map_capture_resized.png`는 행사장 주변을 더 크게 보여주지만 삼성역이 화면에 포함되지 않는다.
- 현재 `index.html`의 지도 이미지는 `img/map_capture_resized.png`를 참조한다.
- 지도는 기존 오시는 길 섹션의 콘텐츠 폭 전체에 원본 비율로 표시된다.

## 확정 설계

1. `index.html`의 지도 이미지 소스를 `img/map_capture.png`로 교체한다.
2. 이미지 파일 자체에는 크롭, 보간, 선명도 필터, 채도 조정, 별도 라벨, 경로선 또는 확대 인셋을 추가하지 않는다.
3. 기존 `.map-image` 배치 규칙을 유지해 콘텐츠 폭 전체에 원본 비율로 표시한다.
4. 기존 주소, `2호선 삼성역 5번출구에서 도보 약 10분` 안내, 네이버 지도 버튼과 주차 안내의 내용 및 순서를 유지한다.
5. 지도 API, iframe, 새로운 외부 링크 또는 지도 상호작용을 추가하지 않는다.

## 정보 역할

- 정적 지도: 삼성역과 행사장이 같은 지역 안에서 어느 방향에 있는지 보여준다.
- 교통 안내 문구: 출발 지점과 예상 도보 시간을 명시한다.
- 네이버 지도 버튼: 실제 길찾기, 확대 및 주변 상세 확인을 제공한다.

지도 내부의 모든 상호명과 도로명을 읽을 수 있게 만드는 것은 성공 기준에 포함하지 않는다.

## 접근성 및 오류 처리

- 기존 대체 텍스트는 삼성역과 행사장 위치를 표시한 지도라는 목적을 계속 설명한다.
- 지도 로딩에 실패하더라도 주소, 교통 안내와 네이버 지도 버튼은 독립적으로 표시되고 사용할 수 있어야 한다.
- 원본 이미지 비율을 유지해 지형과 위치 관계가 왜곡되지 않게 한다.

## 검증 기준

- `index.html`이 `img/map_capture.png`를 참조하고 `img/map_capture_resized.png`를 참조하지 않는다.
- 360px와 640px 뷰포트에서 지도가 잘리거나 왜곡되지 않고 기존 콘텐츠 폭에 맞춰 표시된다.
- 실제 화면에서 삼성역과 행사장 마커를 각각 식별할 수 있고, 두 지점의 대략적인 상대 위치를 파악할 수 있다.
- 주소, 교통 안내, 네이버 지도 버튼과 주차 안내가 기존 순서와 기능을 유지한다.
- 지도 때문에 가로 스크롤, 섹션 겹침 또는 비정상적인 여백이 생기지 않는다.

## 범위 제외

- 지도 이미지 재디자인 또는 신규 캡처 제작
- 지도 위 사용자 정의 표식이나 경로 합성
- 탭 확대, 라이트박스 또는 핀치 줌
- 네이버 지도 API나 iframe 도입

실제 화면 검증에서 두 핵심 지점을 식별하기 어렵다고 판단되면, 이 설계를 임의로 확장하지 않고 별도의 개선 방향을 다시 논의한다.
