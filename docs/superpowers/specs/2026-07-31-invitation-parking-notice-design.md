# 초청장 주차 안내 확정 문구와 인근 주차장 링크 설계

## 목적

현재 `.parking-notice`로 구현된 주차 안내 영역의 임시 문구를 확정된 주차 안내로 교체하고, 방문자가 행사장 인근 유료주차장을 네이버 지도에서 바로 확인할 수 있게 한다. 기존 행사장 위치 확인 링크는 유지하며, 초청장의 외부 이동 링크는 정확히 두 개로 확장한다.

## 확정 콘텐츠

주차 안내는 다음 순서와 문구를 그대로 표시한다.

1. `❗ 본 건물에는 주차가 불가합니다.`
2. `죄송하지만 인근 유료주차장 이용을 부탁드립니다.`
3. `인근 주차장 확인하기` 링크 버튼

느낌표 표시는 단독 느낌표 이모티콘 `❗`를 사용한다. 첫 문장은 강조하고 두 번째 문장은 별도 줄로 표시한다.

## 정보 구조와 시각 표현

- 기존 `.parking-notice` 남색 패널을 확정 주차 안내 컨테이너로 유지한다.
- 안내 문구와 주차장 링크를 같은 컨테이너에 넣어 하나의 의미 단위로 구성한다.
- `❗ 본 건물에는 주차가 불가합니다.`는 주차 불가 사실이 먼저 인지되도록 시각적으로 강조한다.
- `죄송하지만 인근 유료주차장 이용을 부탁드립니다.`는 바로 다음 줄에 일반 본문 강도로 표시한다.
- `인근 주차장 확인하기`는 실제 `<button>`과 JavaScript가 아니라 의미에 맞는 `<a>` 링크로 구현한다.
- 링크는 기존 다섯 색상 팔레트만 사용하고, 최소 높이 44px와 명확한 키보드 포커스를 제공한다.
- 기존 `네이버 지도에서 확인하기` 링크와 시각적 위계가 구분되면서도 동일한 초청장 디자인 체계에 속해야 한다.

## 외부 이동 계약

초청장에는 다음 두 개의 외부 이동 링크만 존재한다.

1. 기존 `네이버 지도에서 확인하기`: 행사장 주소 검색 결과를 연다.
2. 신규 `인근 주차장 확인하기`: 행사장 중심 좌표 인근의 `주차장` 검색 결과를 연다.

신규 링크의 목적지 URL은 다음 값으로 고정한다.

```text
https://map.naver.com/p/search/%EC%A3%BC%EC%B0%A8%EC%9E%A5?c=3zkOlZ%2C2AJB2L%2C15.00%2C0%2C0%2C0%2Cdh
```

이 URL은 네이버 지도에서 `주차장` 검색 결과를 열고, 중심 좌표를 `서울특별시 강남구 테헤란로81길 14` 행사장 인근으로 고정한다. 검색 결과에는 삼성동 일대의 민영·공영 주차장이 표시되어야 한다.

두 링크 모두 새 탭에서 열며 `target="_blank"`와 `rel="noopener"`를 사용한다. 초청장 자체 화면은 링크 클릭 후에도 유지된다.

## 접근성과 실패 처리

- 링크 텍스트만으로 목적을 이해할 수 있어야 한다.
- 키보드 사용자는 주차장 링크에 초점을 이동하고 Enter 키로 열 수 있어야 한다.
- 링크의 클릭 영역은 최소 높이 44px를 유지한다.
- 네이버 지도나 네트워크가 응답하지 않더라도 주차 불가 안내 문구는 독립적으로 계속 표시되어야 한다.
- JavaScript 팝업 호출은 사용하지 않으므로 팝업 차단 정책에 의존하지 않는다.

## 구현 범위

- `index.html`: 주차 placeholder를 확정 문구와 신규 네이버 지도 링크로 교체한다.
- `styles.css`: 기존 주차 패널 안의 문구 위계와 링크 버튼 스타일을 추가한다.
- `scripts/validate-invitation-local.mjs`: 확정 문구, 외부 링크 수, 목적지 URL, 새 탭과 보안 속성을 검증한다.
- 브라우저 검증: 360px와 640px에서 줄바꿈, 클릭 영역, 가로 넘침과 링크 목적지를 확인한다.

## 검증 기준

- 주차 안내에 확정 문구 두 줄과 `❗`가 정확히 표시된다.
- `인근 주차장 확인하기`가 링크 역할과 키보드 접근성을 갖는다.
- 신규 링크가 새 탭에서 열리고 `rel="noopener"`를 가진다.
- 신규 링크가 네이버 지도 `주차장` 검색 결과를 행사장 인근 중심 좌표로 연다.
- 기존 행사장 지도 링크의 문구, URL과 동작은 유지된다.
- `index.html`의 `https://` 외부 링크 요소는 정확히 두 개이며 둘 다 네이버 지도 링크다.
- 360px와 640px에서 안내 문구와 버튼이 잘리거나 겹치지 않고 가로 스크롤이 생기지 않는다.
- 기존 전체 초청장 로컬 검증이 모두 통과한다.

## 범위 제외

- 특정 주차장 추천, 요금, 운영시간 또는 주차 가능 여부를 초청장에 직접 표시하는 기능
- 네이버 지도 API, iframe 또는 위치 권한 사용
- 사용자의 현재 위치를 기준으로 한 주차장 검색
- 기존 행사장 지도 링크의 목적지나 스타일 변경
- 주차장 검색 결과를 초청장 내부에 렌더링하는 기능
