# Intro 반응형 이미지 디자인

## 목표

모바일 360~640px 뷰포트에서 `#intro-section`의 긴 인사말이 우연한 위치에서 줄바꿈되지 않도록, 도입부 전체를 세 가지 기준 폭에서 각각 스테이징한 정적 이미지로 교체한다. 이 초대장은 일회성 콘텐츠이므로 도입부 텍스트의 동적 편집보다 승인된 시각 결과의 재현을 우선한다.

## 이미지 세트

최종 산출물은 모두 `img` 폴더에서 관리한다.

| 디자인 기준 폭 | 적용 뷰포트 | 파일 |
| --- | --- | --- |
| 360px | 360~419px | `img/intro-section-360.png` |
| 480px | 420~559px | `img/intro-section-480.png` |
| 640px | 560~640px 및 기본값 | `img/intro-section-640.png` |

각 이미지는 해당 기준 폭의 CSS 레이아웃을 2배 장치 픽셀 비율로 캡처한다. 따라서 실제 래스터 폭은 각각 720px, 960px, 1280px이며, 파일명에 들어가는 숫자는 표시 기준 폭을 뜻한다. PNG를 사용해 작은 한글 글자의 가장자리와 현재 배경 질감을 손실 없이 보존한다.

## 확정된 시각 구성

세 이미지 모두 현재 `#intro-section`의 다음 요소와 순서를 그대로 유지한다.

1. 호연회계법인 가로형 로고
2. `“호연회계법인”에서 / 새로운 시작을 알려드립니다.` 제목
3. `2026년 8월 12일 (수) · 오전 10시 ~ 오후 9시` 행사 정보
4. 전체 초청 인사말
5. `2026년 8월 / 호연회계법인 부대표 / 세무사 윤성중 드림` 서명

현재 플래티넘·네이비·그린·슬레이트 색상, 반사 배경 이미지, 테두리, 음영, 여백과 정렬을 유지한다. 다른 섹션의 디자인은 변경하지 않는다.

## 폭별 줄바꿈

문단 사이의 공백은 현재 디자인과 동일하게 유지하며, 아래 슬래시(`/`) 위치만 강제 줄바꿈으로 사용한다.

### 360px

- 오랜 공직생활을 마치고 / 호연회계법인에서 세무사로 / 새로운 출발을 하게 되었습니다.
- 그동안 함께해 주신 많은 분들의 / 관심과 격려 덕분에 무사히 / 한 걸음을 내딛게 되었습니다.
- 거창한 약속보다는, 제게 주어진 / 경험을 바탕으로 매 순간 솔직하고 / 치열하게 고민하며 납세자에게 / 진정으로 도움이 되는 사람으로 / 하루하루 살아가려 합니다.
- 이 글을 받으신 모든 분들의 일상에 / 건강과 평안이 가득하시길 기원합니다. / 새롭게 시작하는 자리에 / 귀한 발걸음으로 함께해 주시고 / 응원해 주시면 감사하겠습니다.

## 마크업 전환

기존 `#intro-section`의 화면용 로고·제목·행사 정보·인사말 마크업을 하나의 `<picture>`로 교체한다.

```html
<section id="intro-section" aria-label="호연회계법인 윤성중 부대표 개업 초대 인사말">
  <picture>
    <source media="(max-width: 419px)" srcset="img/intro-section-360.png">
    <source media="(max-width: 559px)" srcset="img/intro-section-480.png">
    <img
      class="intro-section-image"
      src="img/intro-section-640.png"
      alt="호연회계법인 윤성중 부대표의 2026년 8월 12일 개업 초대 인사말"
      fetchpriority="high"
      decoding="async"
    >
  </picture>
</section>
```

이미지 생성 후 실제 픽셀 크기에 맞는 `width`와 `height` 속성을 각 반응형 소스에 기록해 초기 레이아웃 이동을 줄인다. `#intro-section`과 `.intro-section-image`에는 `display: block; width: 100%; height: auto;`를 적용한다. 기존 배경 의사 요소와 이미지 안으로 들어간 자식 요소용 스타일은 제거한다.

도입부가 첫 화면의 핵심 콘텐츠이므로 지연 로딩하지 않는다. 간결한 `aria-label`과 `alt`로 이미지의 목적·행사 주체·날짜를 제공하되, 승인 범위에 따라 전체 인사말을 숨은 HTML로 중복하지 않는다.

## 스테이징 및 생성 흐름

1. 기존 도입부 스타일과 콘텐츠를 재사용하는 전용 스테이징 문서에 360px, 480px, 640px 아트보드를 각각 만든다.
2. 각 아트보드에 이 문서의 강제 줄바꿈을 적용한다.
3. Chromium에서 장치 픽셀 비율 2로 렌더링하고 아트보드 경계만 캡처한다.
4. 캡처 결과를 정해진 세 파일명으로 `img` 폴더에 저장한다.
5. 실제 페이지의 `#intro-section`을 `<picture>` 마크업으로 교체한다.

스테이징 문서는 산출물 재현을 위한 개발용 파일이며 실제 초대장 페이지에는 노출하지 않는다.

## 검증 기준

- 세 PNG 파일이 `img` 폴더에 존재하고 래스터 폭이 각각 720px, 960px, 1280px이다.
- 360px, 419px, 420px, 559px, 560px, 640px에서 의도한 이미지 소스가 선택된다.
- 모든 검증 폭에서 이미지가 컨테이너 너비를 채우고 가로 스크롤, 잘림, 빈 간격을 만들지 않는다.
- 640px 이미지의 문제 문장이 `납세자에게 진정으로 도움이 되는 사람으로 / 하루하루 살아가려 합니다.`로 보인다.
- 로고·제목·행사 정보·전체 인사말·서명이 누락되지 않는다.
- 프로필, 오시는 길, 계좌 정보와 복사 기능은 기존과 동일하게 동작한다.
- 이미지 요청 실패가 없고, 콘솔 오류가 발생하지 않는다.
