# 초청장 정적 주차장 목록 디자인

## 목적

HTML 초청장을 긴 이미지로 변환해 전달하더라도 주차 정보를 별도 링크 없이 확인할 수 있게 한다. 기존 `parking-notice` 안의 네이버 지도 주차장 검색 링크를 제거하고, 인근 유료주차장 세 곳의 이름과 1시간 요금을 같은 화면에 직접 표시한다.

## 범위

- 행사장 위치를 여는 기존 `네이버 지도에서 확인하기` 링크는 유지한다.
- `parking-notice` 안의 `인근 주차장 확인하기` 링크와 해당 리디렉션 URL은 제거한다.
- 주차장명과 1시간 요금만 표시한다.
- 주소, 거리, 운영시간, 잔여 주차면, 길찾기 기능은 추가하지 않는다.
- JavaScript, 지도 API, iframe, 사용자 위치 권한은 사용하지 않는다.

## 안내 문구

주차 영역은 다음 문구와 순서를 사용한다.

1. 제목: `주차 안내`
2. 강조 안내: `본 건물에는 주차가 불가합니다.`
3. 보조 안내: `아래 인근 유료주차장을 이용해 주세요.`
4. 목록 머리글: `주차장명` / `시간당요금`
5. 주차장 3행 목록
6. 각주: `※ 요금은 주차장 사정에 따라 변동될 수 있습니다.`

사과 표현과 느낌표 아이콘은 사용하지 않는다. 제한 사항을 짧고 직접적으로 알린 뒤 대안을 바로 제시한다.

## 주차장 데이터

목록의 순서와 표기는 다음과 같이 고정한다.

| 주차장명 | 1시간 요금 |
| --- | ---: |
| 투루파킹 삼성동빌딩점 주차장 | 5,000원 |
| 투루파킹 삼성역WeWork 주차장 | 6,000원 |
| 투루파킹 LG트윈텔2점 주차장 | 6,000원 |

목록 머리글은 `주차장명`, `시간당요금`으로 표시한다. 각 행에서는 숫자만 보이더라도 의미가 명확하도록 목록 머리글 또는 접근 가능한 레이블을 유지한다.

## 모바일 레이아웃

- 기존 남색 `parking-notice` 카드 안에 안내 문구와 목록을 함께 배치한다.
- 목록은 주차장명을 왼쪽, 요금을 오른쪽에 둔 2열 3행 구조로 표시한다.
- 주차장명은 남은 너비 안에서 자연스럽게 줄바꿈할 수 있다.
- 요금은 `5,000원`, `6,000원` 단위가 줄바꿈되지 않도록 하고 오른쪽 정렬한다.
- 각 행 사이에는 기존 `--platinum` 색상을 낮은 투명도로 사용한 1px 구분선을 넣고, 행 안쪽에는 동일한 세로 여백을 적용한다.
- 별도 카드 세 개, 아이콘 반복, 버튼 형태는 사용하지 않아 세로 길이와 시각적 소음을 줄인다.
- 360px 화면에서 가로 스크롤, 텍스트 겹침, 가격 잘림이 없어야 한다.

## 의미 구조와 접근성

- 주차장 목록은 `<dl>` 또는 동등한 의미의 표 구조로 작성한다.
- 주차장명과 해당 요금의 관계가 보조 기술에서도 명확해야 한다.
- 링크처럼 보이거나 클릭 가능한 스타일을 적용하지 않는다.
- 정보 전달을 색상에만 의존하지 않는다.

## 실패 처리

목록은 정적 HTML 텍스트이므로 네트워크나 외부 서비스 실패에 영향을 받지 않는다. 페이지의 이미지가 로드되지 않더라도 주차 안내와 세 곳의 정보는 그대로 읽을 수 있어야 한다.

## 검증 기준

- `parking-notice` 안에 승인된 제목, 두 문장의 안내, 세 곳의 주차장명과 요금, 요금 변동 각주가 모두 표시된다.
- `인근 주차장 확인하기` 문구와 기존 주차장 검색 URL이 HTML에서 제거된다.
- 행사장 위치용 `네이버 지도에서 확인하기` 링크는 유지된다.
- 세 요금은 각각 지정된 주차장명과 올바르게 대응한다.
- 360px와 640px에서 목록이 카드 밖으로 넘치거나 다른 콘텐츠와 겹치지 않는다.
- 초청장 전체 이미지 캡처에서도 주차 정보가 링크 없이 완결된 내용으로 읽힌다.
