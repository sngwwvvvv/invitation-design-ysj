# MMS 가로 합본용 상세 섹션 확장 설계

## 목표

국세청 인터넷게시판용 가로 합본에서 `intro`와 `details`를 각각 `971 × 1641px`로 맞춘다. `details`는 기존 이미지를 가로로 늘리지 않고 `mms_design.html`의 콘텐츠를 넓은 레이아웃으로 다시 배치해 글자, 인물 사진, 지도 비율을 보존한다. 최종 합본은 `1942 × 1641px` PNG로 만든다.

## 범위와 보존 조건

- 기존 `mms_design.html` 기반 640px MMS 화면과 `mms_01_intro.*`, `mms_02_details.*`는 변경하지 않는다.
- 가로 합본 전용 렌더링 경로를 별도로 둔다.
- 모든 문구, 색상, 인물 사진, 지도, 경력 목록, 주차 안내, 계좌 안내 내용을 그대로 유지한다.
- 콘텐츠를 가로 방향으로 비균등 확대하거나 잘라내지 않는다.
- `intro`는 현재처럼 원본 비율을 유지해 `971 × 1641px`로 확대한다.

## 넓은 상세 레이아웃

합본 전용 렌더러에서만 상세 섹션의 기준 폭을 971px로 설정한다. 글자 크기는 기존 데스크톱 값을 유지하고, 섹션 좌우 패딩과 그리드 폭을 넓은 캔버스에 맞게 조정한다.

- 프로필: 인물 사진의 종횡비를 유지하고 경력 영역의 가용 폭을 넓힌다.
- 오시는 길: 지도 비율을 유지하며 중앙 배치하고, 주소와 교통 안내는 자연스럽게 확장된 폭을 사용한다.
- 주차 및 계좌 카드: 카드 배경과 구분선은 넓은 콘텐츠 폭을 활용하되 문구와 숫자의 비율은 유지한다.
- 세로 높이: 섹션 패딩과 간격을 조정해 상세 패널의 최종 캡처 경계를 정확히 1641px로 맞춘다. 콘텐츠를 자르거나 겹치게 해 높이를 맞추지 않는다.

## 출력 흐름

1. `mms_design.html`을 971px 합본 전용 모드로 연다.
2. 전용 CSS 오버라이드를 적용하고 이미지와 글꼴 로딩을 기다린다.
3. 상세 섹션을 `971 × 1641px` PNG로 캡처한다.
4. 기존 `mms_01_intro.png`를 비율 유지하여 `971 × 1641px`로 확대한다.
5. 두 패널을 여백 없이 가로로 결합해 새 버전 파일로 저장한다.

## 검증 기준

- 상세 패널과 intro 패널이 각각 정확히 `971 × 1641px`이다.
- 최종 합본이 정확히 `1942 × 1641px`이고 중간 또는 하단에 빈 공백이 없다.
- 모든 텍스트가 잘림, 겹침, 의도하지 않은 줄바꿈 없이 읽힌다.
- 인물 사진과 지도는 원래 종횡비를 유지한다.
- 기존 640px MMS 이미지와 공개 초청장 파일에는 변경이 없다.
- 최종 PNG를 실제 렌더링하여 시각적으로 확인한다.
