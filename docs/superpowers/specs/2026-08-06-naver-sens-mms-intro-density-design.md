# Naver SENS MMS 01 이미지 밀도 개선 명세

## 목표

`mms_img/mms_01_intro.jpg`의 넓은 여백을 줄이고 로고, 제목, 일자, 본문 문구, 서명을 더 크게 보여 준다. 출력 규격과 기존 문구는 유지하며, 어느 요소도 가로 또는 세로로 잘리거나 캔버스 밖으로 넘치지 않아야 한다.

## 승인된 방향

사용자가 승인한 A안(균형 확대)을 적용한다.

- 최종 캔버스는 기존과 동일한 `1080 × 1440px`이다.
- 1080px 전용 콘텐츠 폭을 `760px`에서 `860px`로 확대한다.
- 좌우에는 최소 `110px`의 안전 여백을 유지한다.
- 로고, 제목, 일자 pill, 본문, 서명을 기존 대비 약 12~16% 범위에서 함께 확대한다.
- 전체 콘텐츠 묶음은 캔버스 안에서 수직 중앙 정렬을 유지한다.
- 본문의 문단 구분과 강제 줄바꿈, 모든 문구는 변경하지 않는다.
- 360px, 480px, 640px 프리뷰 레이아웃과 `mms_02_details.jpg`는 변경하지 않는다.

## 목표 치수

1080px 전용 스타일에 다음 값을 적용한다.

- 콘텐츠 폭: `860px`
- 캔버스 좌우 padding: `110px`
- 로고 폭: `340px`
- 제목 글자 크기: `52px`
- 일자 pill 글자 크기: `26px`
- 본문 글자 크기: `25px`
- 서명 글자 크기: `23px`

세로 간격과 line-height는 1440px 안에서 전체 콘텐츠가 잘리지 않도록 함께 조정한다. 확대 후 콘텐츠의 실제 외곽 상자는 캔버스 내부에 있어야 하며, 배경 테두리와 겹치지 않아야 한다.

## 검증 기준

- 렌더링된 `01` JPEG가 정확히 `1080 × 1440px`이다.
- JPEG 파일 크기는 기존 Naver SENS 안전 한도인 `290KB` 이하이다.
- `intro-content`와 모든 하위 요소의 좌우 경계가 `0..1080px` 안에 있다.
- 콘텐츠 최소 좌우 안전 여백이 각각 `110px` 이상이다.
- 콘텐츠의 상단과 하단이 `0..1440px` 안에 있고 세로 스크롤 overflow가 없다.
- 제목과 일자 문구가 의도치 않게 추가 줄바꿈되지 않는다.
- `mms_02_details.jpg`, `index.html`, `styles.css`, 기존 PNG 및 `output/mms-wide/` 결과는 변경하지 않는다.
- 최종 JPEG를 직접 열어 텍스트 잘림, 요소 겹침, 지나치게 치우친 여백이 없는지 시각 확인한다.

## 범위 제외

- 문구, 날짜, 서명 내용 변경
- 배경 이미지나 색상 변경
- 두 번째 MMS 이미지 재배치 또는 재렌더링
- `main` 브랜치 병합 또는 PR 생성
