# Naver SENS 전용 MMS 세로 이미지 설계

## 목표

`mms_design.html`의 내용을 Naver SENS 전용 MMS 이미지 두 장으로 다시 렌더링한다. 첫 이미지는 `intro section`만, 두 번째 이미지는 `career section`부터 계좌 안내까지 포함한다. 두 결과물은 동일한 `1080 × 1440px` 세로형 3:4 캔버스를 사용하고, 텍스트·인물 사진·지도·장식 요소를 자르거나 비균등하게 늘리지 않는다.

## 출력물

- `mms_img/mms_01_intro.jpg`: `#intro-section`만 포함한 `1080 × 1440px` JPEG
- `mms_img/mms_02_details.jpg`: `.profile-section`부터 `.account-section`까지 포함한 `1080 × 1440px` JPEG
- 각 JPEG는 파일 크기를 `290KB 이하`로 제한해 Naver SENS의 300KB 업로드 한도에 안전 여유를 둔다.
- 기존 파일명을 유지해 현재 MMS 작업 흐름에서 바로 교체할 수 있게 한다.
- PNG는 최종 납품 범위에 포함하지 않는다. 렌더링이나 시각 검증에 필요한 무손실 중간 파일은 `output/` 아래에만 생성한다.

## 보존 조건

- 초청장 문구, 일정, 경력, 주소, 교통, 주차장, 계좌 정보는 변경하지 않는다.
- 현재 색상, 시각적 위계, 인물 사진과 지도 원본 비율을 유지한다.
- 콘텐츠를 잘라내거나 숨기지 않는다.
- 캔버스 크기를 맞추기 위해 전체 결과물을 가로 또는 세로 방향으로 비균등 확대하지 않는다.
- 큰 빈 여백을 추가해 높이를 맞추지 않고, 전용 레이아웃의 간격과 열 배치를 조정해 캔버스를 채운다.
- 공개 초청장인 `index.html`과 그 반응형 동작은 변경하지 않는다.

## 렌더링 구조

### 인트로 이미지

기존 래스터 이미지를 `1080 × 1440px`로 확대하지 않고, `scripts/intro-section-stage.html`의 원본 HTML 구성에서 Naver SENS 전용 레이아웃을 렌더링한다. 로고, 제목, 인사말, 행사 일정, 서명 요소의 순서와 표현을 유지하면서 전용 캔버스에 맞게 세로 간격과 콘텐츠 폭을 조정한다.

### 상세 이미지

`mms_design.html`의 `.profile-section`, `.directions`, `.account-section`을 Naver SENS 전용 모드에서 다시 배치한다. `1080px`의 가로 공간을 활용해 프로필과 경력, 지도와 안내 정보, 주차 및 계좌 영역이 `1440px` 안에서 자연스럽게 이어지도록 패딩, 간격, 그리드 폭을 조정한다. 인물 사진과 지도에는 비율 보존 규칙을 적용한다.

### 캡처와 변환

Chromium에서 이미지와 글꼴 로딩을 완료한 뒤 각 전용 캔버스를 정확히 `1080 × 1440px`로 캡처한다. 무손실 중간 캡처에서 JPEG를 생성하며, 해상도를 낮추지 않고 JPEG 품질만 단계적으로 조정해 `290KB 이하`에 맞춘다. 압축 결과의 글자와 얇은 선이 눈에 띄게 손상되면 레이아웃의 불필요한 질감을 줄이고 다시 압축하며, 크기 조건을 맞추기 위해 픽셀 크기를 변경하지 않는다.

## 검증

자동 검증은 다음 조건을 확인한다.

- 두 JPEG가 모두 정확히 `1080 × 1440px`이다.
- 각 JPEG 파일이 `290KB 이하`이다.
- 파일 형식이 실제 JPEG이며 `.jpg` 확장자와 일치한다.
- 인트로 결과에는 `#intro-section`의 콘텐츠만 존재한다.
- 상세 결과는 `.profile-section`에서 시작해 `.account-section` 하단에서 끝난다.
- 캡처 대상 내부에 가로·세로 넘침, 잘림, 겹침이 없다.
- 인물 사진과 지도 이미지의 표시 비율이 원본 비율과 일치한다.
- 공개 초청장 검증은 기존과 동일하게 통과한다.

최종 JPEG 두 장을 실제로 열어 텍스트 선명도, 줄바꿈, 여백 균형, 섹션 경계, 사진 왜곡 여부를 시각적으로 확인한다.

## 범위 제외

- Naver SENS API를 통한 실제 업로드 또는 문자 발송
- 발송 대상 번호나 메시지 본문 관리
- 다른 MMS 사업자용 `750 × 1000px` 변형
- RCS, 카카오톡 이미지 메시지 또는 웹 초청장 디자인 변경
- 기존 가로 합본 이미지 재생성
